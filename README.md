# Chat Service

## Описание

Chat Service является центральным сервисом системы.

Он управляет жизненным циклом чатов, принимает сообщения пользователей, организует взаимодействие с LLM Adapter Service и Storage Service.

---

## Основные функции

- создание чатов;
- удаление чатов;
- переименование;
- отправка сообщений;
- получение истории;
- установка промптов;
- получение списка чатов пользователя.

---

## Архитектура

```
                Router Service
                       │
                       ▼
                Chat Service
                /          \
               ▼            ▼
Storage Service    LLM Adapter Service
```

---

## Логика работы

### Создание чата

1. Получение запроса.
2. Создание объекта чата.
3. Сохранение через Storage Service.
4. Возврат chatId.

---

### Отправка сообщения

1. Проверка существования чата.
2. Сохранение сообщения пользователя.
3. Отправка сообщения в LLM Adapter.
4. Получение ответа модели.
5. Сохранение ответа.
6. Возврат результата клиенту.

---

## Используемые технологии

- Java 21
- Spring Boot
- Spring Web
- OpenFeign (или RestTemplate)
- Lombok

---

## Зависимости

- Storage Service
- LLM Adapter Service

---

## Основные операции

| Операция | Описание |
|----------|----------|
| createChat | Создание чата |
| writeToChat | Отправка сообщения |
| deleteChat | Удаление |
| renameChat | Переименование |
| getMessages | Получение истории |
| setPrompt | Установка промпта |
